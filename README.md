Belerofonte-Baycodec-JS
Extensión de navegador (Manifest V3) que identifica las tecnologías de la página que visitas: CMS, frameworks, UI frameworks, servidores, CDN, analítica, pagos, etc. Funciona como Wappalyzer. Además analiza la tipografía que usa realmente la página.
